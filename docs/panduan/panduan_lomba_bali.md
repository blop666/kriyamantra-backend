## 5. Apa yang Dimaksud MVP dan Eligible AI?

## Minimum Viable Product (MVP)

MVP adalah versi awal produk yang sudah memiliki fungsi utama yang dapat digunakan dan didemonstrasikan. Produk belum harus sempurna, tetapi juri harus dapat membuktikan bahwa solusi benar-benar bekerja.

| Belum Cukup | Sudah Termasuk MVP |
| --- | --- |
| Ide di proposal saja | Website dapat dibuka dan fungsi utama dapat digunakan |
| Mockup/Figma tanpa fungsi | User dapat memasukkan input dan memperoleh output sistem |
| Slide presentasi atau video konsep | AI benar-benar dipanggil/digunakan dalam alur produk |
| Screenshot statis | Juri dapat menguji alur utama produk |

## Definisi Eligible AI

## PRINSIP UTAMA

AI harus menjadi bagian material dari fungsi utama solusi dan memberikan kemampuan yang relevan terhadap masalah yang diselesaikan. Menggunakan AI hanya untuk membantu coding tidak dihitung sebagai integrasi AI pada produk.

## Contoh Teknologi AI

Contoh berikut diperbolehkan sepanjang penggunaannya relevan dan dapat dijelaskan:

- Large Language Model (LLM) / Generative AI

- Computer Vision

- Recommendation System

- Machine Learning / Classification

- Predictive Model / Forecasting

- Natural Language Processing

- Speech Recognition / Speech AI

- OCR berbasis AI

- AI Agent / Agentic Workflow

- Teknologi AI lain yang mekanisme dan manfaatnya dapat dipertanggungjawabkan

## AI untuk Membantu Coding

Penggunaan ChatGPT, GitHub Copilot, Claude, Gemini, Cursor, atau tools AI lain sebagai development assistant diperbolehkan. Penggunaannya wajib diungkapkan pada AI & Technology Disclosure. Peserta tetap bertanggung jawab memahami, menguji, dan mempertanggungjawabkan source code yang disubmit.

## 7. Aturan GitHub dan Deployment

## Repository GitHub

Repository dapat bersifat public atau private. Jika private, peserta wajib memberikan akses read-only kepada akun GitHub panitia/juri selama proses penilaian.

## Isi Minimum Repository

- Source code aplikasi yang disubmit.

- README.md.

- .env.example tanpa API key atau secret asli.

- Dokumentasi/screenshot bila relevan.

- AI & Technology Disclosure atau tautan ke bagian disclosure.


- Riwayat commit yang dapat diverifikasi.

## Security Rule

## JANGAN PERNAH MENYIMPAN SECRET DI PUBLIC REPOSITORY

API key, password, private token, database credential, atau secret lain tidak boleh dicantumkan di source code public. Gunakan environment variable dan sediakan .env.example yang hanya menunjukkan nama variabel, bukan nilainya.

## Version Locking

Pada setiap deadline submission, peserta wajib menunjukkan versi yang dinilai menggunakan commit hash atau release/tag. Rekomendasi penamaan: v1.0-submission untuk Tahap 1 dan v2.0-final untuk final. Perubahan setelah deadline tidak otomatis menjadi bagian dari versi yang dinilai.

## Deployment

- Website harus dapat diakses juri tanpa proses instalasi yang tidak wajar.

- Platform hosting bebas sepanjang aplikasi dapat diuji.

- Jika membutuhkan login, peserta wajib menyediakan akun demo khusus juri.

- Credential demo dikirim melalui kanal/form panitia, bukan public repository.

- Peserta bertanggung jawab memastikan kuota hosting/API cukup selama masa penjurian.

## Pre-existing Project

Produk yang telah dikembangkan sebelum kompetisi diperbolehkan sepanjang peserta merupakan pihak yang sah dalam pengembangannya, produk belum dikomersialisasikan secara massal, dan status pengembangan sebelumnya diungkapkan secara transparan. Peserta harus menjelaskan bagian yang sudah ada sebelum kompetisi dan bagian yang dikembangkan/ditingkatkan untuk kompetisi.

## 12. Pelanggaran dan Diskualifikasi

Pelanggaran material dapat menyebabkan pengurangan nilai, pembatalan status finalis, atau diskualifikasi sesuai keputusan panitia. Contoh pelanggaran antara lain:

- Plagiarisme atau klaim palsu atas karya pihak lain.

- Pemalsuan demo atau manipulasi yang menyesatkan juri mengenai fungsi produk.

- Repository atau website sengaja tidak sesuai dengan produk yang diklaim.

- Menyembunyikan penggunaan karya pihak lain atau status pre-existing project yang material.
